## 技术栈速览（定稿）

| 层 | 选型 |
|----|------|
| 架构模式 | 模块化单体（单进程 Spring Boot，按模块分包） |
| 后端 | Java 17 + Spring Boot 3.3 + MyBatis-Plus + MySQL 8.0 + Redis 7 |
| 鉴权 | JWT + Redis 黑名单（封禁/注销即时生效） |
| App | uni-app X（一套代码出 iOS + Android；W1 有 3 天技术验证，失败降级普通 uni-app） |
| 管理后台 | Vue 3 + Vite + Element Plus + ECharts |
| 媒体 | 阿里云 OSS + CDN，服务端签名直传 |
| 站内信 | 拉取式动态轮询（会话页 5s / 前台 30s / 后台停止），不做长连接 |
| 部署 | 单机 4C8G（大陆，已备案）+ Nginx HTTPS，MySQL 每日备份至 OSS |

## 开发约定（重要红线）

- 价格用整数"分"存储，禁止浮点
- 删除一律软删除（is_deleted），禁止物理删除
- 用户身份只从登录态取，禁止信任前端传的 userId
- 短信限频：同号 1 分钟 1 条、每日 5 条
- 密码加盐哈希存储，禁止明文
- 跨模块只允许调 Service 接口，禁止跨模块直查表
- 埋点 5 事件必须随 MVP 版本带上（见需求文档 7.5）

详细说明见 `产品/开发避坑清单.md` 与 `产品/架构与技术栈选型.md`。
