# 社区 App 需求速览

## 一句话描述

做一款 iOS / Android App，初期约 1 万用户；App 只有普通用户端，管理员使用 Web 后台；核心业务是管理员发布任务、用户浏览后联系管理员，同时支持二手物品交易和类似微博的论坛交流，并通过接入广告变现。

## 端与角色

- **App**：只有普通用户端，无管理入口。
- **Web 后台**：只有管理员使用，所有管理操作都在 Web 端完成。
- **角色**：只有普通用户和管理员两类，管理员权限一致。

## App 底部导航

交易 / 任务 / 论坛 / 我的

## 交易模块

- 交易页顶部是物品分类：2 排，每排 4 个，共 8 个分类。
- 分类下方是**广告 Banner**。
- 下面是交易物品列表：一排两个。
- 物品包含：视频、图片、介绍、收藏、价格、第三方联系方式、购买状态。
- 购买状态只保留：在售、已售，去掉"已预定"和橙色状态。
- 用户可发布二手物品，管理员在 Web 后台审核、下架、删除。
- 只做信息撮合，不做平台内支付、担保和退款仲裁。

## 任务模块

- 任务页顶部是**广告 Banner**。
- 下面是任务信息流。
- 任务由**管理员在 Web 后台发布**，App 用户只能浏览。
- 任务卡片只展示：
  - 任务标题
  - 任务简述
  - 报酬 / 积分 / 线下结算说明
  - 发布时间（V1.3 起）
  - 截止时间
  - 图片、文字等附件
- 不展示任务状态、接单按钮、需要人数、已接人数。
- 用户感兴趣后，进入任务详情，点击**联系管理员**，后续线下沟通。
- App 内没有接单、没有任务状态流转、没有"我的接单"。

## 论坛模块

- 类似微博的信息流。
- 管理员和用户都可以发布消息，内容包含文字、图片、视频等。
- 顶部为 SVG"发布"图标按钮（V1.3.2 起，替代搜索位；取消右下角悬浮加号），进入发布帖子页。
- 互动为微信朋友圈样式：卡片上是 SVG 点赞图标和 SVG 评论图标，直接点击操作；"···"按钮不弹菜单，点击直接跳转举报页面（V1.3.5 起）；收藏在详情页操作。
- 卡片上点赞数、评论数突出显示；高赞评论预览（点赞最高 1～2 条）弱化小字展示；评论列表内热评前置。
- 帖子发布即展示，不再先审后发（V1.3.3 起）：敏感词自动拦截 + 管理员巡查 + 举报兜底；二手发布仍先审后发。
- 公告帖醒目样式展示（高亮边框 + 角标），最新一条固定在信息流顶部；已取消置顶功能。
- 管理员在 Web 后台审核、置顶、删除、禁言。
- 论坛信息流中可插入广告。

## 我的模块

包含：

- 个人资料
- 我的发布
- 我的收藏
- 消息通知
- 联系管理员
- 设置

没有"我的接单"，也没有 App 管理入口。

## Web 管理后台

管理员在 Web 后台完成：

- 任务管理：发布、编辑、下架、删除
- 交易管理：审核、下架、删除
- 论坛管理：审核、置顶、删除、禁言
- 用户管理：查看、封禁、解封
- 举报管理
- 广告管理
- 公告管理
- 系统设置
- 数据看板

## 广告与规模

- App 需要接入广告变现。
- 初期用户约 1 万人。
- 初期架构：单服务器 + 自建数据库 + 对象存储 + CDN。

## V1.2 / V1.3 修订要点（2026-10-09 确认）

以上业务边界不变。补充确认的结论（详细规则以 `需求文档.md` V1.2 为准）：

- 站内信：MVP 做最简版，两个用途——联系管理员 + 买卖家留言（"联系卖家"走站内信异步留言，不做实时聊天）；卖家第三方联系方式改为选填、不再公开展示；
- 消息通知：MVP 为 App 内消息中心，推送留二期；"我的发布"页直接展示审核状态；
- 注销账号、拉黑用户：MVP 必须；
- 评论审核：统一为敏感词过滤 + 先发后审；
- 游客可浏览交易/任务/论坛，操作时（发布/收藏/评论/联系）才要求登录；
- 任务里的"积分"是管理员填写的文字展示，平台无积分体系；
- 图片/视频接内容安全审核服务（机审 + 人工复审），审核时效 24 小时内；
- 埋点：MVP 最小 5 事件（启动、页面访问、广告曝光、广告点击、发布行为）。

## V1.3 修订要点（2026-10-09 确认）

- 任务卡片与任务详情增加"发布时间"展示；
- 论坛信息流互动改为微信朋友圈样式：点赞/评论/收藏/举报收进帖子"···"菜单，评论默认收起；帖子详情页内可直接操作；
- 联系管理员区分两类会话：任务咨询（任务详情发起，自动关联任务，用于对接工作）与客服咨询（"我的"入口，一般问题，类似客服）；管理员后台可按类型筛选，任务咨询优先处理。

- 取消"置顶"功能（后台与帖子状态同步移除）。

## V1.3.2 修订要点（2026-10-09 确认）

- 高赞评论在论坛首页帖子卡片上直接预览（点赞数最高的 1～2 条，不用点开）；
- "···"弹出菜单只有 SVG 点赞、SVG 收藏两项；评论改为卡片上的 SVG 图标直接入口；举报移至帖子详情页；
- 论坛首页顶部改为"发布"按钮（替代搜索位），取消右下角悬浮加号；发布帖子页说明已补充（文字 + 最多 9 图或 1 视频，先审后发）。

## V1.3.3 修订要点（2026-10-09 确认）

- 论坛顶部发布入口改为 SVG 图标；
- 卡片视觉层级：点赞数/评论数突出显示，高赞评论预览弱化（小字号低调样式）；
- "···"菜单增加 SVG 举报，共三项：点赞、收藏、举报；
- 论坛帖子取消先审后发：发布即展示，敏感词自动拦截 + 管理员巡查 + 举报兜底（二手仍先审后发；系统设置保留审核开关，违规频发可随时切回）。

- "···"菜单定为两项：SVG 点赞、SVG 举报（去掉收藏）；
- 收藏帖子功能保留，入口移到帖子详情页，卡片上不提供。

## V1.3.5 修订要点（2026-10-09 确认）

- "···"按钮取消弹出菜单（无背景弹层），点击直接跳转举报页面；
- 点赞改为卡片上的 SVG 图标直接操作（与评论图标并排）。

## V1.4 修订要点（2026-10-09 确认）

- 注册流程重构为三个独立页面：①手机号验证（底部带短信限频提示）→ ②设置密码（强度条三格 + 眼睛切换明密文 + 规则 8～20 位含字母数字）→ ③设置昵称（头像可跳过、昵称必填限 12 字、性别选填）；顶部步骤条同步高亮：前序✓、当前数字、后续灰色；
- 登录方式调整为密码 + 验证码双通道；未注册手机号不再自动注册，提示"去注册"；
- 新增忘记密码找回（验证码校验后重置）与修改密码；
- 密码加盐哈希存储、登录错误次数限制写入安全需求。
- 人机验证：确认暂不接入（记入二期清单；若刷帖严重优先在短信/发帖/评论点位补）。

## 技术选型（2026-10-10 定稿）

详细论证见 `架构与技术栈选型.md`（5 条 ADR）：

- 架构：模块化单体（单进程 Spring Boot，按业务模块分包，不做微服务）；
- 后端：Java 17 + Spring Boot 3.3 + MyBatis-Plus + MySQL 8.0 + Redis 7 + JWT；
- App：uni-app X，一套代码出 iOS + Android（W1 有 3 天技术验证，失败降级普通 uni-app）；
- 管理后台：Vue 3 + Element Plus + ECharts；
- 站内信：动态轮询（会话页 5 秒 / 前台 30 秒 / 后台停止），不做长连接；
- 部署：单机 4C8G + Nginx + OSS/CDN，MySQL 每日备份。
