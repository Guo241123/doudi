## 四、已按文档实现、仅需确认无误的点

- 论坛首页信息流为**帖子 / 广告混排**，按 `itemType` 分支渲染；公告帖置顶、高赞评论预览弱化展示、点赞数/评论数突出显示。
- 帖子卡片互动仅用 SVG 图标（点赞 / 评论 / “···”跳举报），点击正文进入详情。
- 详情页互动仅用 SVG 图标（点赞 / 评论 / 收藏 / 分享 / 举报）；评论支持点赞、回复（二级，不做无限嵌套）。
- 游客可浏览信息流 / 详情 / 评论（接口 `auth=false`）；点赞、评论、收藏、举报、发帖需登录（未登录统一引导登录）。
- 发布帖子：正文 1~1000 字，图片 ≤9 张或 1 个视频（≤60 秒），走 `#26` OSS 直传（`biz=POST`）。
- 列表/详情错误由页面自行渲染“加载中 / 失败重试 / 空”态（读接口传 `manual=true` 关闭统一 toast）。
- 广告曝光/点击经 `#45` 上报（失败静默）。
