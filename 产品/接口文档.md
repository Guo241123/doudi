## 一、通用约定

### 1.1 基础

- Base URL：`https://api.<域名>/api/v1`（管理后台为 `/api/admin/v1`）
- 请求/响应体均为 `application/json`（除 OSS 文件直传）
- 时间格式：`yyyy-MM-dd HH:mm:ss`，时区 GMT+8
- 金额单位：**分**（整数），前端展示时再换算为元

### 1.2 统一返回体

```json
{ "code": 0, "message": "ok", "data": { } }
```

`code = 0` 成功；非 0 见 1.5 错误码表。HTTP 状态码只表达传输层问题，业务结果一律看 `code`。

### 1.3 鉴权

- 请求头：`Authorization: Bearer <JWT>`（App token 30 天，后台 2 小时 + 刷新）
- 标注"需登录"的接口未带 token / token 失效 → `40101`
- 服务端一律从 JWT 解析用户身份，接口中不存在 `userId` 入参

### 1.4 分页

- **App 端游标分页**：请求 `cursor`(整数，首页传 0) + `size`(默认 20，上限 50)；返回 `{ "list": [...], "nextCursor": 12345, "hasMore": true }`
- **后台页码分页**：请求 `page`(≥1) + `size`；返回 `{ "list": [...], "total": 88 }`

### 1.5 错误码表

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40001 | 参数错误（message 说明具体字段） |
| 40002 | 内容命中敏感词，发布被拦截 |
| 40003 | 验证码错误或已过期 |
| 40101 | 未登录 / token 失效 |
| 40301 | 无权限（含被封禁、拉黑限制、注销处理中） |
| 40401 | 资源不存在或已删除 |
| 40901 | 重复操作 |
| 42901 | 触发短信限频（message 含今日剩余次数） |
| 42902 | 登录错误次数过多，已锁定 |
| 50000 | 服务器内部错误 |

### 1.6 关键枚举

| 枚举 | 取值 |
|------|------|
| 性别 gender | `M` 男 / `F` 女 / `U` 保密（默认） |
| 二手状态 status | `UNDER_REVIEW` 待审核 / `ON_SALE` 在售 / `SOLD` 已售 / `REJECTED` 已拒绝 / `OFF_SHELF` 已下架 |
| 帖子状态 | `PUBLISHED` 已发布 / `DELETED` 已删除 / `ANNOUNCEMENT` 公告 |
| 会话类型 type | `TASK_CONSULT` 任务咨询 / `CUSTOMER` 客服咨询 / `TRADE` 联系卖家 |
| 举报类型 targetType | `ITEM` 二手 / `POST` 帖子 / `COMMENT` 评论 / `USER` 用户 |
| 举报原因 reason | `SPAM` 垃圾广告 / `PORN` 色情低俗 / `FRAUD` 诈骗 / `COPYRIGHT` 侵权 / `OTHER` 其他 |
| 举报状态 | `PENDING` 待处理 / `RESOLVED` 已处理 |
| 短信场景 scene | `REGISTER` / `LOGIN` / `RESET` / `CHANGE_MOBILE` |

### 1.7 用户对象 User（各接口复用）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | long | 用户 ID |
| nickname | string | 昵称 |
| avatarUrl | string | 头像完整 URL（OSS+CDN） |
| gender | string | M / F / U |
| bio | string | 个人简介（可为空） |
| registerTime | string | 注册时间（仅本人资料返回） |

## 二、App 端接口

> "需登录：否"的接口游客可访问；带 `★` 的字段为后端计算/下发字段，前端只读。

### 2.1 认证与账号

#### 0. 获取图形验证码（占位）
`GET /auth/captcha` ｜ 需登录：否

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| captchaId | string | 验证码会话 ID（提交时带上） |
| imageBase64 | string | 验证码图片（base64） |

规则：2 分钟有效；**一次性**——校验一次（无论对错）后立即作废，需重新获取。

#### 1. 发送短信验证码
`POST /auth/sms/send` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号，11 位数字 |
| scene | string | 是 | 短信场景及校验规则：`REGISTER` 要求手机号未注册 / `LOGIN` 要求已注册 / `RESET` 要求已注册 / `CHANGE_MOBILE` 要求新手机号未注册 |
| captchaId | string | 是 | #0 返回的题目编号 |
| captchaCode | string | 是 | 用户输入的图形码答案 |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| leftToday | int | 该手机号今日剩余可发条数（前端可显示"今日还可发送 N 次"，用完置灰按钮） |

错误：`40003` 图形验证码错误/过期；`42901` 触发限频；REGISTER 时手机号已注册 → `40901`；LOGIN/RESET 时未注册 → `40401`；**被封禁或注销处理中的账号：LOGIN/RESET → `40301`**。

#### 2. 注册①：校验手机号与验证码
`POST /auth/register/check-mobile` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号 |
| smsCode | string | 是 | 6 位短信验证码，5 分钟有效 |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| registerToken | string | 注册流程凭证，**完成注册（#4）或 10 分钟过期后失效**；注册②③凭它继续（非正式登录态） |

错误：`40003` 验证码错误/过期；`40901` 手机号已注册（提示"去登录"）。
防爆破：同一手机号验证码**校验错误累计 5 次后该验证码作废**，须重新发送（下同，适用于所有 smsCode 校验接口）。

#### 3. 注册②：设置密码
`POST /auth/register/password` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| registerToken | string | 是 | #2 返回 |
| password | string | 是 | 8～20 位，必须含字母与数字；服务端加盐哈希存储 |
| confirmPassword | string | 是 | 确认密码，须与 password 一致 |

返回 data：空（前端进注册③）。
实现注记：注册中间态（手机号 + 密码哈希）存 **Redis**（key = registerToken），#4 完成才落库；token 过期/完成注册即删除。

#### 4. 注册③：设置昵称，完成注册
`POST /auth/register/nickname` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| registerToken | string | 是 | #2 返回 |
| nickname | string | 是 | 1～12 字，去首尾空格后校验，重名允许 |
| gender | string | 否 | M / F / U，默认 U |
| avatarKey | string | 否 | #25 上传后返回的 fileKey；不传用默认头像 |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| token | string | 登录凭证（完成即登录） |
| user | User 对象 | 见 1.7 |

#### 5. 密码登录
`POST /auth/login/password` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 手机号 |
| password | string | 是 | 注册时设置的密码 |

返回 data：`{ token, user }`（同 #4）。
错误：`40401` 账号不存在（提示去注册）；`42902` **同一手机号**连续错 5 次锁定 15 分钟（防撞库，同时同 IP 也做限频）；`40301` 账号被封禁（message 含原因）或注销处理中。

#### 6. 验证码登录
`POST /auth/login/sms` ｜ 需登录：否

请求参数：`mobile`(string, 是)、`smsCode`(string, 是)。

返回 data：`{ token, user }`。未注册 → `40401` 提示"去注册"。验证码错误防爆破规则同 #2（错 5 次作废）。

#### 7. 忘记密码-重置
`POST /auth/password/reset` ｜ 需登录：否

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mobile | string | 是 | 注册手机号 |
| smsCode | string | 是 | RESET 场景验证码 |
| newPassword | string | 是 | 规则同注册② |
| confirmPassword | string | 是 | |

返回 data：`{ token }`（重置后自动登录）。

#### 8. 退出登录
`POST /auth/logout` ｜ 需登录：是

请求参数：无。返回 data：空（token 作废）。

#### 9. 注销账号
`POST /user/deactivate` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| confirm | boolean | 是 | 前端二次确认后传 true；传 false 直接 40001 |

返回 data：空。账号进入 7 天注销处理期：期内登录返回 `40301`（message："账号注销处理中"）；7 天后定时任务清理数据。**注销提交后该用户所有 token 立即失效。**

#### 10. 我的资料
`GET /user/profile` ｜ 需登录：是

返回 data：User 对象（1.7）+ `mobile`(脱敏，如 138****5678)。

#### 11. 编辑资料
`PUT /user/profile` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | string | 否 | 1～12 字 |
| gender | string | 否 | M / F / U |
| bio | string | 否 | ≤100 字 |
| avatarKey | string | 否 | 新头像的 fileKey |

返回 data：更新后的 User 对象。

#### 12. 更换手机号
`PUT /user/mobile` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| newMobile | string | 是 | 新手机号（须未注册） |
| smsCode | string | 是 | CHANGE_MOBILE 场景验证码（发到新手机号） |

规则：换绑成功后**清除该用户所有设备的 token**，用户需重新登录（防 token 被盗后改绑盗号——高危操作统一规则，见实现注记 10）。

#### 13. 修改密码
`PUT /user/password` ｜ 需登录：是

请求参数：`oldPassword`(否，与 smsCode 二选一)、`smsCode`(否)、`newPassword`(是)、`confirmPassword`(是)。两种方式至少传其一。

规则：修改成功后**清除该用户所有设备的 token**（含当前会话，用户重新登录——高危操作统一规则，见实现注记 10）。

#### 14. 我的信息概览（我的页面头部）
`GET /user/summary` ｜ 需登录：是

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| user | User | 本人资料 |
| unreadCount | int | 未读消息数（进"我的"页刷新一次） |
| myItemCount | int | 我的发布-二手数 |
| myPostCount | int | 我的发布-帖子数 |

#### 16. 任务详情

### 2.3 交易（二手）

#### 17. 分类列表
`GET /trade/categories` ｜ 需登录：否

返回 data.list：`{ id, name, sort, iconUrl }`（按 sort 排序，即交易页 2×4 八宫格）。

#### 18. 物品列表
`GET /trade/items` ｜ 需登录：否（收藏态字段登录才返回）

请求参数：`categoryId`(long, 否，不传=全部)、`cursor`(int, 是)、`size`(int, 否)。

返回 data.list 每项：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | long | 物品 ID |
| title | string | 标题 |
| coverUrl | string | 封面图或视频首帧 |
| priceFen | int | 价格（分） |
| bargainable | boolean | 是否可议价 |
| status | string | 只返回 `ON_SALE` / `SOLD`（绿色/灰色标签） |
| favorited | boolean | 是否已收藏（未登录恒 false） |

**序列化红线**：任何列表/详情接口不得出现卖家联系方式字段。

#### 19. 物品详情
`GET /trade/items/{id}` ｜ 需登录：否

返回 data：#18 字段 + `images[]`(url 数组)、`videoUrl?`、`description`、`publishTime`、`seller{userId, nickname, avatar}`、`canChat`★(登录且非本人且在售时 true，前端显示"联系卖家"按钮)、`disclaimer`★(免责声明文案)、`isMine`★。**不含联系方式**。

#### 20. 发布二手
`POST /trade/items` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | ≤30 字 |
| images | string[] | 图片/视频至少其一 | fileKey 数组，≤9 张 |
| videoKey | string | 否 | 视频 fileKey（与 images 互斥：有视频则 images 为空） |
| description | string | 是 | 物品介绍 ≤500 字 |
| priceFen | int | 是 | 价格，单位分，>0 |
| categoryId | long | 是 | 分类 |
| contact | string | 否 | 第三方联系方式（选填，仅存档，任何接口不返回） |
| bargainable | boolean | 是 | 是否可议价 |

返回 data：`{ id, auditStatus: "UNDER_REVIEW" }`（先审后发）。

#### 21. 编辑二手
`PUT /trade/items/{id}` ｜ 需登录：是（仅本人）

请求参数：同 #20。规则：`UNDER_REVIEW` / `ON_SALE` 状态可编辑；编辑后回到 `UNDER_REVIEW` 重新审核。

#### 22. 卖家状态操作
`PUT /trade/items/{id}/status` ｜ 需登录：是（仅本人）

请求参数：`action`(string, 是)：`OFF_SHELF` 下架 / `MARK_SOLD` 标记已售 / `PUT_ON` 重新上架（仅已下架物品，回 UNDER_REVIEW）。

#### 23. 我的发布（二手）
`GET /trade/my-items` ｜ 需登录：是

请求参数：`cursor`、`size`、`auditStatus`(可选筛选)。

返回 data.list：#18 字段 + `auditStatus`（UNDER_REVIEW/ON_SALE/REJECTED/OFF_SHELF）+ `rejectReason?`（拒绝原因，通知同步在消息中心）。

#### 24. 收藏 / 取消收藏（二手）
`POST /trade/items/{id}/favorite` ｜ `DELETE /trade/items/{id}/favorite` ｜ 需登录：是

幂等：重复收藏/取消不报错，返回成功。

#### 25. 我的收藏（二手）
`GET /trade/favorites` ｜ 需登录：是

请求参数：`cursor`、`size`。返回 list 为 #18 卡片结构（已售/下架的物品仍显示但置灰标 `unavailable: true`）。

### 2.5 文件上传（OSS 直传）

#### 26. 获取直传签名
`POST /upload/token` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileType | string | 是 | `IMAGE` / `VIDEO` |
| biz | string | 是 | 用途：`AVATAR` 头像 / `ITEM` 二手 / `POST` 帖子 |

返回 data：

| 字段 | 类型 | 说明 |
|------|------|------|
| uploadUrl | string | OSS 上传地址（PUT） |
| fileKey | string | 文件 key（后续业务接口引用它） |
| headers | object | 上传请求头（含签名） |
| expireAt | string | 签名过期时间 |

规则：IMAGE ≤10MB、VIDEO ≤100MB/60s（服务端 OSS 回调校验 + 内容安全机审，机审不通过 fileKey 作废）。

### 2.6 论坛

#### 27. 信息流
`GET /forum/feed` ｜ 需登录：否

请求参数：`cursor`(int, 是)、`size`(int, 否，默认 20)。

返回 data.list（混排序列，每项先看 `itemType`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| itemType | string | `POST` 帖子 / `AD` 广告 |
| pinned | boolean | ★公告置顶标记（仅最新一条公告为 true，固定在序列最前） |
| id | long | 帖子 ID 或广告位素材 ID |
| author | User | 发布者（公告帖 author 为管理员账号，昵称后带"官方"标识由前端根据 isAnnouncement 渲染） |
| publishTime | string | |
| content | string | 文字内容 |
| media[] | array | `{type: IMAGE/VIDEO, url}` |
| likeCount / commentCount | int | ★突出显示的计数 |
| liked | boolean | 当前用户是否已赞 |
| hotComments[] | array | ★高赞评论预览，前 1～2 条：`{commentId, author{nickname}, content}`（前端弱化小字样式） |
| isAnnouncement | boolean | 公告帖标记（醒目样式：高亮边框+角标） |
| ad{slot, adId, materialUrl, jumpType} | object | 仅 itemType=AD 时有：广告素材与上报 id |

#### 28. 发帖（先发后审）
`POST /forum/posts` ｜ 需登录：是

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 是 | 1～1000 字 |
| images | string[] | 图片/视频至少其一 | fileKey 数组，≤9 张 |
| videoKey | string | 否 | 视频 fileKey |

返回 data：`{ id }`。命中敏感词 → `40002`（message 提示修改）；未命中**立即发布**。

#### 29. 帖子详情
`GET /forum/posts/{id}` ｜ 需登录：否

返回 data：#27 帖子字段 + `isMine`★、`canReport`★(恒 true，详情页举报入口)。拉黑作者的帖子返回 `40401`（对被拉黑方不可见）。

#### 30. 帖子点赞 / 取消
`POST /forum/posts/{id}/like` ｜ `DELETE .../like` ｜ 需登录：是

幂等：重复点赞返回成功。返回 data：`{ likeCount, liked }`（前端直接刷新计数）。

#### 31. 帖子收藏 / 取消
`POST /forum/posts/{id}/favorite` ｜ `DELETE .../favorite` ｜ 需登录：是（详情页入口）

#### 32. 评论列表（热评前置）
`GET /forum/posts/{id}/comments` ｜ 需登录：否

请求参数：`cursor`、`size`。

返回 data.list 每项：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | long | 评论 ID |
| author | User | |
| content | string | |
| replyTo | object | 回复目标：`{commentId, nickname}`（仅二级回复有；不做无限嵌套） |
| likeCount | int | |
| liked | boolean | |
| hot | boolean | ★是否热评（点赞数最高前 3 条排最前并置 hot=true，其余按时间倒序） |
| createTime | string | |

#### 33. 发表评论 / 回复
`POST /forum/posts/{id}/comments` ｜ 需登录：是

请求参数：

## 四、关键实现注记（给后端，逐条对应红线）

1. **联系方式永不入返回体**：#18/#19 序列化层剔除该字段；`contact` 仅存档供平台纠纷协查。
2. **点赞幂等双保险**：Redis SET 去重先行，DB 唯一索引（user_id + target_id + target_type）兜底，重复请求返回成功。
3. **拉黑过滤统一三口**：信息流、评论列表、站内信三个查询口统一过滤黑名单（量小用服务层过滤）。
4. **敏感词**：帖子/评论同步调库（词库后台可维护）命中即拒（40002）；二手结果作为审核辅助。
5. **图片机审**：OSS 回调 → 内容安全 API → 写审核结果；不通过 fileKey 作废，引用它的业务自动进入拒绝/人工队列。
6. **操作日志 AOP**：后台写接口统一切面记录（管理员 ID、动作、目标、时间）。
7. **游标实现**：`WHERE id < ? ORDER BY id DESC LIMIT ?`；公告/广告是"插入项"，不参与游标。
8. **封禁即时性**：封禁/注销写 Redis（`ban:user:{id}`），鉴权过滤器统一拦截（ADR-005）。
9. **埋点写放大**：#46 事件先写内存队列，批量落表（1 万用户量级无需 MQ）。
10. **高危账号操作统一清 token**：修改密码（#13）、重置密码（#7）、更换手机号（#12）、注销（#9）、后台封禁（#58）执行成功后，**删除该用户在 Redis 中的全部会话 token**——否则改密码后，旧设备/盗取的 token 依然有效，等于没改。当前登录的这台设备也一并登出，属可接受体验。
