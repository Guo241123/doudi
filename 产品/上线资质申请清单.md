# 上线资质申请清单

**项目**：社区任务与二手交易 App（主体：个体工商户）
**日期**：2026-10-09
**用法**：按"第一批（现在就办）→ 第二批（开发期办）→ 第三批（上架前办）"的顺序推进；每项写清去哪办、要什么材料。具体费用/审核时长以各平台官网现价为准，本文标注的是经验值（估算）。

## 一、第一批：现在就办（都是长周期项）

### 1. 个体户营业执照
- **去哪办**：当地市场监督管理局，或线上"各省政务服务网 / 一网通办"。
- **材料**：经营者身份证、经营场所证明（多数地区允许住宅登记，各地政策不同，办理时问清）。
- **关键注意**：经营范围必须包含"软件开发""信息技术服务"之类目——后面广告入驻、备案都看这个。执照下来后顺便完成税务登记。

### 2. 域名
- **去哪办**：阿里云 / 腾讯云等注册商，买一个 `.com` 或 `.cn`，完成域名实名认证（用个体户名义更好，备案时主体一致省事）。

### 3. ICP 备案（域名备案）
- **去哪办**：在你的云服务商备案系统里提交（阿里云/腾讯云都有备案控制台）。
- **前提**：服务器必须买在中国大陆（境外服务器无法备案）。
- **材料**：营业执照、经营者身份证、核验照片/人脸识别、服务器信息。
- **耗时**：服务商初审 2～3 天 + 管局审核 1～3 周。
- **注意**：备案期间域名不能解析到大陆服务器对外提供服务，所以要在开发早期就启动。

### 4. App 备案
- **是什么**：2023 年起工信部要求 App 也备案（和域名备案是两回事，都要做）。
- **去哪办**：同一套备案系统，App 备案通常与主体 ICP 备案关联提交。
- **材料**：App 名称、包名（iOS/Android）、公钥签名、平台信息。
- **注意**：需要 App 基本开发定型后填包名等信息，但主体备案先做，App 备案随提交——别等开发完才弄，管局审核也要几周。

### 5. 软件著作权
- **去哪办**：中国版权保护中心官网（线上申请），或找代理。
- **材料**：源代码（前、后各连续 30 页）、用户手册或设计说明书、主体身份证明。
- **耗时**：普通通道 30～60 个工作日；代理加急可缩到数个工作日（几百到上千元），看你上架时间紧不紧。
- **为什么必须**：国内主流安卓应用商店（华为、小米、OPPO、vivo 等）上架基本都要软著，且**软著主体要和上架账号主体一致**。
- **登记名称建议**：就叫 App 的正式名字，和商店上架名称保持一致。

### 6. 苹果开发者账号
- **去哪办**：Apple Developer 官网。
- **类型选择**：
  - 个人账号（$99/年）：注册快，可上架，适合个体户阶段先用；
  - 组织/公司账号：需要公司实体 + 邓白氏编码（D-U-N-S），个体户一般走组织账号较难，**建议先用个人账号上架，主体升级公司后再转移**。
- **注意**：付款需要支持外币的支付方式；账号信息（名字）会出现在 App 商店"开发者"一栏。

## 二、第二批：开发期办（联调要用）

### 7. 短信服务（阿里云 / 腾讯云短信）
- **材料**：实名账号、短信签名（用 App 名，需执照）、验证码模板。
- **审核**：签名/模板 1～3 天。
- **注意**：个人主体签名受限，用个体户实名顺利得多；这是注册登录的命脉，W2 联调前必须可用。

### 8. 内容安全审核服务（腾讯云 / 阿里云内容安全）
- **是什么**：图片/视频/文字机审接口（图片鉴黄、涉政检测等）。
- **开通**：实名账号即可开通，按调用量付费（二手/帖子图片审核必用）。
- **对应需求**：需求文档 4.7.2（图片/视频机审 + 人工复审）。

### 9. 微信开放平台认证（可选，做微信登录才需要）
- **去哪办**：微信开放平台 → 开发者资质认证。
- **费用**：300 元/年。
- **注意**：**个人主体不能认证，个体户可以**；认证通过后创建移动应用（要填 App 包名和签名）。不做微信登录就跳过（需求文档里微信登录是"可选支持"）。

### 10. 广告平台入驻（穿山甲 / 优量汇）
- **去哪办**：穿山甲流量变现平台（字节）、优量汇（腾讯）官网注册开发者账号。
- **材料**：营业执照、经营者身份信息、结算账户（对公账户；能否用经营者个人卡以平台要求为准，入驻时确认）、App 信息（名称/包名/下载地址——上架前可先提交，App 上架后补充）。
- **审核**：约 1～2 周。
- **结论**：个体户可以入驻（个人开发者不能变现）；平台可同时入驻，互相对比填充率和价格。

### 11. 对公银行账户（个体户）
- **为什么**：广告结算一般打款到对公账户；部分平台支持经营者个人卡，入驻时确认。
- **去哪办**：执照下来后带材料到银行开立个体户对公账户，通常数个工作日，注意问清账户管理费。

## 三、第三批：上架前办

### 12. 安卓应用商店开发者账号（华为 / 小米 / OPPO / vivo / 应用宝等）
- **材料**：执照（多数商店要求企业或个体户，个人受限）、软著（与主体一致）、App 信息。
- **注意**：每个商店单独注册、单独提审，材料基本一套通用；首发起 3～5 个主流商店即可。

### 13. 对象存储 + CDN
- **开通**：云服务商实名后开通即可，按量付费。二手图片/帖子图片/头像全走这里。

### 14. 隐私政策 + 用户协议
- **要求**：必须有**可公开访问的网页 URL**（苹果/安卓上架审核都会点开看），App 内也要能打开。
- **内容要点**：收集哪些信息（手机号、头像、昵称）、怎么用、怎么保存、用户权利（查看/更正/删除/注销——对应需求文档 4.1.3 的注销功能）、第三方 SDK 清单（短信、内容安全、广告 SDK 都要列进去，这是审核常查点）。
- **建议**：用同行业模板改，上架前请懂行的朋友或法务过一遍。

## 四、不需要办的（常见误解）

| 事项 | 为什么暂不需要 |
|------|----------------|
| 等级保护测评 | 1 万用户的小型 App 通常不强制，用户量上来后评估 |
| 支付业务许可证 | 平台不做支付（只做信息撮合），不涉及 |
| ICP 经营许可证（EDI） | 平台不直接收费经营信息服务，ICP 备案即可；若后期做会员收费再评估 |
| 网络文化经营许可证 | 不做游戏/文化产品交易，不涉及 |
