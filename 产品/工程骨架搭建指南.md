# 工程骨架搭建指南

**依据**：需求文档 V1.4.1、《架构与技术栈选型》、《接口文档》V1.1
**日期**：2026-10-10
**目标**：W1 内把三端骨架立起来——后端能启动、能连 MySQL/Redis、Swagger 可访问；App 四个 Tab 能切；管理后台能登录壳。业务逻辑一律不写，只搭结构。
**对应目录**：`app/backend/`、`app/frontend/ios|android|admin-web`（uni-app X 一套代码产双端，工程本体放 `frontend/` 下的 uniapp-x/，打包产物才是 ios/android，见 2.1 说明）

## 〇、开发环境清单（先装齐）

| 工具 | 版本 | 用途 |
|------|------|------|
| JDK | 17（LTS） | 后端 |
| Maven | 3.8+ | 后端构建 |

## 一、后端骨架（app/backend/）

### 1.1 创建方式

Spring Initializr（IDEA 内置或 start.aliyun.com）→ Maven → jar → 勾选：Spring Web、Lombok、MySQL Driver、Data Redis、Validation。其余依赖（MyBatis-Plus、JWT、Hutool、SpringDoc）手动加 pom。

### 1.2 依赖清单（pom.xml 需要的 artifactId）

| 依赖 | 用途 |
|------|------|
| spring-boot-starter-web | Web |
| spring-boot-starter-validation | 参数校验（配合 40001） |
| spring-boot-starter-data-redis | Redis（验证码/限频/黑名单/未读数） |
| mybatis-plus-spring-boot3-starter | ORM（注意 boot3 专用版） |
| mysql-connector-j | 数据库驱动 |
| jjwt（api/impl/jackson 三件） | JWT 生成与校验 |
| springdoc-openapi-starter-webmvc-ui | Swagger 接口文档 |
| hutool-all | 工具包（图形验证码生成、脱敏、随机数） |
| lombok | 减少样板代码 |

### 1.3 包结构（对应架构文档第六节，一次建齐空包）

```
backend/src/main/java/com/shequ/
├── ShequApplication.java
├── common/
│   ├── result/            # 统一返回体 Result<T>、错误码枚举 ErrorCode
│   ├── exception/         # 业务异常 BusinessException + 全局异常处理器
│   ├── auth/              # JWT 工具、登录拦截器（黑名单校验在此）
│   └── util/              # 图形验证码、脱敏、时间工具
├── config/                # Redis 配置、Swagger 配置、CORS 配置、MyBatis-Plus 分页插件
└── module/                # ★ 业务模块（每个模块内部再分三层）
    ├── user/   ├── controller/ ├── service/ ├── mapper/ └── entity/
    ├── task/   （同上四层）
    ├── trade/  （同上）
    ├── forum/  （同上）
    ├── message/（同上）
    ├── ads/    （同上）
    └── analytics/（同上）
backend/src/main/java/com/shequ/job/      # 定时任务：超期下架、注销清理、备份触发
backend/src/main/resources/
├── application.yml        # 公共配置
├── application-dev.yml    # 本地：连 localhost 的 MySQL/Redis
├── application-prod.yml   # 生产：服务器配置（不入 Git，用模板占位）
└── mapper/                # MyBatis XML（如需要）
```

**模块纪律（W1 就要立规矩）**：`module/user` 与 `module/trade` 之间只能调 Service 接口，出现跨模块 Mapper 调用视为代码评审不通过。

### 1.4 配置文件骨架（application.yml 需要的配置段）

```yaml
spring:
  profiles.active: dev
  datasource: (url/username/password — dev 指向 localhost)
  data.redis: (host/port)
mybatis-plus: (分页插件、驼峰转换)
jwt: (secret、expire-days: 30、admin-expire-hours: 2)
oss: (endpoint/bucket/access-key 占位 — W5 才真用)
sms: (占位 — W2 接入)
content-safety: (占位 — W5 接入)
springdoc: (开启)
```

**纪律**：所有密钥类配置（OSS AK、短信 AK、JWT secret）在 prod 用环境变量注入，**不入 Git**——dev 配置里也放占位符而非真实值。

### 1.5 common 层要造的"公共积木"（W1 的实质工作）

| 组件 | 对应接口文档约定 |
|------|------------------|
| `Result<T>` 统一返回体 | code/message/data 三段式 |
| `ErrorCode` 枚举 | 错误码表 11 项 |
| `BusinessException` + 全局异常处理器 | 业务异常自动转对应 code，兜底 50000 |
| JWT 工具 + 登录拦截器 | 签发/校验、Redis 黑名单校验（封禁/注销即踢） |
| 参数校验异常转换 | Validation 报错 → 40001 + 具体字段 |
| Swagger 分组 | App 接口 / Admin 接口两组 |

### 1.6 W1 完成标志

- [ ] `mvn spring-boot:run` 启动无报错
- [ ] Swagger（/swagger-ui.html）可访问，能看到模块分组
- [ ] 提供一个临时 ping 接口返回 `{"code":0,...}` 验证统一返回体
- [ ] MySQL/Redis 连接成功（启动日志无异常）

## 二、App 骨架（uni-app X）

### 2.1 目录归属说明

uni-app X 一个工程同时产出 iOS 和 Android 安装包，所以**工程本体放 `app/frontend/uniapp-x/`**；`frontend/ios/` 与 `frontend/android/` 存放各自平台的离线打包工程/自定义基座（W1 技术验证时再决定是否需要离线打包，默认云端打包可先空着）。

### 2.2 创建方式

HBuilderX → 新建项目 → **uni-app x** → 默认模板（Vue3）。创建后先把 HBuilderX 与 uni-app X SDK **锁定为同一个正式版**（工具菜单记下版本号，写入项目 README，团队所有人一致）。

### 2.3 目录结构

```
uniapp-x/
├── pages.json              # 路由与 TabBar 配置（四 Tab：trade/task/forum/my）
├── manifest.json           # App 包名、图标、权限声明
├── pages/
│   ├── login/              # 登录页、忘记密码
│   ├── register/           # 注册①②③（三页，步骤条组件复用）
│   ├── trade/              # 交易首页、分类列表、物品详情、发布二手
│   ├── task/               # 任务首页、任务详情
│   ├── forum/              # 论坛首页、帖子详情、发布帖子、举报页
│   ├── message/            # 会话列表、会话聊天页
│   └── my/                 # 我的、个人资料、我的发布、我的收藏、设置、拉黑列表
├── components/             # 通用组件：步骤条、物品卡片、帖子卡片、SVG 图标组件
├── static/icons/           # SVG 图标（与 UI 设计规范对应：赞/评论/收藏/举报/发布）
├── api/                    # ★ 接口层：按模块一个文件（auth.js/trade.js/forum.js...）
│   └── request.js          # 网络封装（唯一出口）
└── utils/                  # token 存取、时间格式化
```

### 2.4 request.js 网络封装要处理的事（对接口文档通用约定）

| 职责 | 规则 |
|------|------|
| baseURL | `dev` 指向本机后端（真机调试用局域网 IP，不是 localhost） |
| token 注入 | 自动带 `Authorization: Bearer` |
| 统一返回体 | `code != 0` 统一弹 message；`40101` 清 token 跳登录页；`40301` 区分封禁/注销提示 |
| 游标分页 | 封装"传入 cursor，返回 {list, nextCursor, hasMore}"的标准翻页逻辑 |
| 失败静默 | 广告/埋点上报（#45/#46）失败不弹窗 |
| 轮询管理 | 未读数轮询：会话页 5s / 前台 30s / onHide 停止（对应 ADR-004） |

### 2.5 W1 完成标志

- [ ] 技术验证四项完成（广告 SDK 插件 / OSS 直传 / 滚动性能 / iOS 真机）——**任何一项失败先停下定降级，再继续搭**
- [ ] 四 Tab 框架可切换，页面为空壳

## 三、管理后台骨架（app/frontend/admin-web/）

### 3.1 创建方式

`npm create vite@latest admin-web -- --template vue` → 安装：vue-router、pinia、axios、element-plus、echarts。

### 3.2 目录结构

```
admin-web/
├── src/
│   ├── api/                # 按后台菜单分文件（dashboard/tasks/trade/forum/users/reports/messages/ads/settings）
│   ├── views/              # 每个菜单一个目录，与 5.2 菜单一一对应
│   │   ├── login/
│   │   ├── dashboard/      # 数据看板（ECharts）
│   │   ├── tasks/          # 任务管理
│   │   ├── trade/          # 交易管理 + 分类管理
│   │   ├── forum/          # 论坛管理（巡查/公告）
│   │   ├── users/          # 用户管理（封禁/解封）
│   │   ├── reports/        # 举报管理
│   │   ├── messages/       # 站内信工作台
│   │   ├── ads/            # 广告管理
│   │   └── settings/       # 系统设置 + 操作日志
│   ├── router/             # 路由 + 登录守卫（无 token 跳 /login）
│   ├── stores/             # Pinia：管理员信息、token
│   ├── utils/request.js    # axios 封装（同 App 端职责：统一返回体、401 跳登录）
│   └── components/         # 通用表格/弹窗封装
└── vite.config.js          # dev 代理 → http://localhost:8080（免 CORS 调试）
```

## 四、联调约定（三端对齐）

| 项 | 约定 |
|----|------|
| 端口 | 后端 8080 ｜ 管理后台 dev 5173（Vite 默认）｜ App 真机连局域网 IP:8080 |
| CORS | 后端 CORS 配置放行 5173；App 端无 CORS 问题（原生请求） |
| 接口文档 | 后端启动后 Swagger：`http://localhost:8080/swagger-ui.html`，按模块分组即接口文档的两大节 |
| 接口变更纪律 | 只增不改删（接口文档头部约定）；改了先在群里发字段 diff，三方确认 |
| 提交 | 后端/前端/后台各自独立 Git 仓库（或 monorepo 三目录），commit 前跑通启动 |

## 五、W1 骨架期坑点速查

| 坑 | 提示 |
|----|------|
| MyBatis-Plus 启动报错 | 99% 是没带 spring-boot3 的 starter |
| App 真机连不上后端 | 手机和电脑必须同 WiFi，baseURL 用电脑局域网 IP，后端防火墙放行 8080 |
| uni-app X 版本漂移 | 团队所有人 HBuilderX 版本一致，锁死 |
| Redis 连不上 | Windows 本地建议直接 WSL 或 Docker 跑 Redis 7，别用老旧 Windows 移植版 |
| 时间字段时区错乱 | 数据库连接串加 `serverTimezone=GMT%2B8`，后端全局配 GMT+8 |
| 密钥进 Git | 第一天就建好 `.gitignore`（application-prod.yml、.env），别等泄漏 |
